    Méthode : prédiction Shryock figée

    Les valeurs en pointillé sont les prédictions de Mark A. Shryock, telles que déduites de son article du 8 mai 2026. Elles couvrent la période 8 mai → 31 août 2026 et incluent ses dates critiques : Europe « tank bottoms » fin mai, USA « tank bottoms » 4 juillet, cascade alimentaire juillet-août.

    Ces valeurs ne changent jamais. Elles servent de référence pour évaluer la précision du prophète.

    Scénario A — Apaisement

    Négociation Iran-USA, Hormuz rouvre partiellement, prix se stabilisent.

    Action : décélérer le plan, revenir au calendrier original (août-octobre).

    Scénario B — Stagflation prolongée

    Hormuz reste tendu, prix élevés persistants, disruptions sectorielles.

    Action : maintenir le plan accéléré, hiver = priorité.

    Scénario C — Escalade / cascade

    Élargissement régional, ruptures locales, panique d'achat.

    Action : accélérer encore — compléter vague 2 dans la semaine.

    Indicateurs déclencheurs de bascule

    • A → B : reprise trafic Hormuz < 50 % ; Brent paper > 90 $ ; essence QC > 2,00 $/L
    • B → C : Europe en « tank bottoms » confirmé ; faillites aéronautiques en cascade ; rationnement annoncé ; essence QC > 2,50 $/L
    • C → B : libérations massives SPR coordonnées ; accord Iran-USA ; reprise trafic Hormuz > 60 %
    • B → A : Brent paper < 80 $ stable ; essence QC < 1,75 $/L ; trafic Hormuz > 80 %

    Garde-fous

    • Consultation 2 fois par semaine, point. Pas de doomscrolling entre les rapports.
    • Sources institutionnelles uniquement (EIA, FAO, gouvernement, presse établie).
    • Si bascule vers Scénario C : prendre le temps de réfléchir avant d'agir. La panique ne décide jamais.
